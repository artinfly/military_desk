1. С чего начать

  1. Войдите под своей учётной записью. На главной видны ваши роли и доступные показатели.
  2. Для поиска сотрудника откройте «Учётные карточки». Для сводных выгрузок используйте «Отчёты».
  3. Для загрузки кадровых сведений откройте «Обмен данными». Кнопки редактирования и операций доступны по правам.

На скриншотах показаны вымышленные данные. Нажмите на изображение, чтобы открыть его в полном размере.

2. Найти и заполнить карточку

  1. Введите ФИО или табельный номер. По умолчанию отображаются работающие. При необходимости измените фильтр «Работа».
  2. Выберите нужные фильтры. У цеха и ВУС есть окно поиска по названию или коду. Нажмите «Применить фильтры».
  3. Нажмите на ФИО. На вкладке «Общее» находятся основные сведения. Остальные вкладки открывают документы, адреса, назначения и воинский учёт.
  4. Для новой записи нажмите «Добавить карточку». Заполните обязательные поля и сохраните. Разделы добавляйте в самой карточке.

3. Скачать отчёт

  1. В меню откройте «Отчёты». Если у отчёта есть период, заполните нужные даты.
  2. Нажмите «Скачать Excel». «Форма к распоряжению» содержит основную форму и два приложения на отдельных листах.
  3. Чтобы выгрузить сотрудников по своим фильтрам, примените их в списке карточек и нажмите «Выгрузить в Excel».

В «Численности» строка «Кол-во работающих БК» показывает последнее значение, полученное при сохранённой кадровой загрузке. До первой такой загрузки ячейка пустая.

4. Распечатать справку

  1. Откройте карточку работающего забронированного сотрудника и нажмите «Справка о бронировании» рядом с кнопками редактирования.
  2. Нажмите «Печать / сохранить PDF». В предпросмотре проверьте формат А4 и альбомную ориентацию. Одна справка занимает половину листа.
  3. Для печати на свободной правой половине используйте «Печать справа». Для справок по цеху откройте их в разделе «Отчёты» и выберите цех. Пакет раскладывается по две справки на лист.

Администратор учёта может изменить текст и реквизиты через «Изменить шаблон».

5. Бронирование и операции

  1. Подготовьте XLSX. В первой колонке укажите ФИО, во второй — СНИЛС. Первая строка содержит заголовки. Сопоставление идёт по СНИЛС.
  2. В «Операциях» выберите бронирование или разбронирование, приложите файл и укажите номер приказа. Для бронирования выберите вид учёта и, при необходимости, группу учёта.
  3. Нажмите кнопку операции и проверьте количество обработанных записей и сообщение о ненайденных сотрудниках.

Здесь же доступны смена вида учёта и обновление списка спец. уволенных. Массовые операции сохраняют изменения в базе.

6. Кадровый архив

  1. Подготовьте ZIP с vus.csv. Если нужно обновить дополнительные коды, добавьте vus_ext.csv в тот же архив.
  2. В «Обмене данными» выберите ZIP и нажмите «Проверить архив». Изучите итоги и замечания. Проверка откатывает изменения.
  3. Выберите файл снова, отметьте «Применить изменения в базе» и нажмите «Загрузить». Успешная загрузка появится в журнале.

7. Категории и DBF

  1. В «Обмене данными» откройте «Категории работников». Найдите запись по ОКПДТР или включите «Без категории».
  2. Выберите категорию по названию и нажмите «Сохранить» в строке.
  3. Для подготовки DBF выберите вид исходного файла, загрузите его и нажмите «Подготовить выгрузку». В ZIP находятся результат и сведения об отклонённых записях.

8. Частые вопросы

Сотрудника нет в списке

Сбросьте фильтры, выберите «Все» в фильтре «Работа» и попробуйте найти сотрудника по табельному номеру.

Нет кнопки редактирования или нужного раздела

Доступ определяется ролью. Обратитесь к администратору, если операция входит в ваши обязанности.

Не скачивается отчёт или не запускается операция

Прочитайте сообщение на странице. Для некоторых отчётов, операций и подготовки DBF администратор должен настроить виды учёта на этой установке.

Архив не загружается

Проверьте формат ZIP и наличие обязательного файла. Если сервис указывает имя файла и строку, исправьте её в исходной выгрузке и повторите проверку.
